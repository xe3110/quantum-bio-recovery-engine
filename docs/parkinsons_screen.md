# Parkinson's disease combination screen — protocol and results

A deterministic, multi-parameter, discovery-stage screen over a curated panel of
**35 Parkinson's candidates** scored at **three orders** — 35 monotherapies, 595
pairs, 4,734 triples — against a **90-gene directional disease signature** and a
**cached STRING v12 interactome**.

It is **not** a clinical combination recommendation. Adding a chronic medication
to an elderly patient on dopaminergic therapy carries adherence, falls,
orthostatic, and psychiatric costs that no in-silico score can quantify. Every
output is a hypothesis for experimental validation.

The standing procedure this run instantiates — what a registry entry must carry,
how the k-ary scorer is defined, and the checklist for adding the next disease —
is in the [disease campaign protocol](disease_campaign_protocol.md). **This
document states only what is specific to Parkinson's.** The companion screen for
multiple sclerosis is [here](ms_publication_protocol.md); the campaign that
designs a molecule rather than ranking existing ones is
[here](denovo_design_protocol.md).

```bash
python -m experiments.parkinsons.run_combination_screen --top 25 --seed 7
python -m experiments.parkinsons.run_combination_screen --quick     # smoke run
pytest -q tests/test_combination_scoring.py
```

---

## 1. What this screen does that the MS screen does not

| | MS screen (v3) | Parkinson's screen |
|---|---|---|
| Orders scored | pairs only | **k = 1, 2, 3** |
| Scoring module | `ms_scoring` — vocabulary as module constants | `combination_scoring` — vocabulary from the registry |
| Monotherapy baseline | none | 35 singles, **same code path** as a triple |
| Cross-order comparison | n/a | efficacy block only, with the rule enforced by a test |
| "Does the k-th agent earn its place?" | n/a | `score_gain_over_best_subset` |
| Regimen cost | route + half-life mismatch, as a bonus | route burden + half-life spread, as a **penalty** |

The two are not numerically comparable — different disease, different signature,
different panel, different weights — but the k = 2 arithmetic is identical by
construction, and tests pin the reduction.

## 2. Inputs specific to Parkinson's

- **`data/pd_expression.csv`** — 90 genes across 13 pathways with `logFC`,
  curation `confidence`, and an explicit `desired_direction`.

  > **This signature is weaker evidence than the MS entry's.** It is curated
  > from literature knowledge rather than derived from a specific cohort, and
  > the registry's own `provenance` block says so. Replace it with a versioned,
  > stage-stratified human dataset before publication use.

- **`data/drugs/parkinsons_panel_v1.json`** — 35 records regenerated by
  `python -m tools.curate_pd_panel`, which fails if any target gene is absent
  from the signature. 16 approved, 6 phase 3, 13 phase 2; 29 mechanism classes.

  The panel is weighted deliberately toward agents that **failed** in phase 2/3.
  Parkinson's has an unusually well-documented record of neuroprotection
  failures, which makes it a strong source of negative controls — five, where
  the MS panel has four.

- **`data/networks/string_pd_network.tsv`** — STRING v12, *H. sapiens*,
  confidence ≥ 0.4. The registry declares one gene alias, `GBA` → `GBA1`.
  STRING still uses the old symbol for glucocerebrosidase; unmapped, the single
  most common genetic risk factor in Parkinson's would have had zero network
  leverage and dropped out silently.

- **Vocabulary** — five therapeutic axes (`symptomatic_dopaminergic`,
  `synuclein_proteostasis`, `mitochondrial_rescue`,
  `neuroinflammation_control`, `trophic_support`) and eight risk domains
  (`dyskinesia`, `impulse_control`, `orthostatic_hypotension`, `psychiatric`,
  `cardiac`, `hepatic`, `somnolence`, `gastrointestinal`).

  Psychosis and impulse-control disorders carry the highest risk weights,
  because they are the usual reasons a regimen is abandoned; dyskinesia is close
  behind as the dose-limiting toxicity of the most effective drug in the
  disease. **This vocabulary shares no therapeutic axis with MS and only
  `cardiac`/`hepatic` among risk domains** — which is the point. A screen that
  reported `infection` as a worst risk domain for Parkinson's would be reporting
  MS's vocabulary.

- **Delivery** — `requires_cns_exposure: true`. The pathology is
  intraparenchymal from the outset, and the degenerating substantia nigra is not
  reachable from the periphery. Consequently `compartment_complementarity` is
  scored here as CNS **coverage** rather than compartment *spread*: a regimen
  that never reaches the parenchyma cannot modify the disease however well it
  reverses a transcript. (In MS, where compartmentalised inflammation sits
  behind an intact barrier and peripheral immunosuppression plateaus, the same
  field means spread. The registry decides which.)

## 3. Results — monotherapy versus combination

Compared on the efficacy block only. `priority_score` is **not** in this table
and must not be: it includes complementarity and separation terms a single agent
cannot earn by construction (see the [rule](disease_campaign_protocol.md#comparing-across-orders--the-rule)).

| order | n | median reversal | max reversal | % beating best monotherapy | max gain | % sub-additive | *p* |
|---|---|---|---|---|---|---|---|
| 1 | 35 | 0.0160 | 0.0519 | — | — | 0% | — |
| 2 | 530 | 0.0340 | 0.1000 | 26.4% | +0.0481 | 12.8% | ~0 |
| 3 | 4,734 | 0.0578 | 0.1409 | 58.5% | +0.0890 | 36.0% | ~0 |

*p* is Mann-Whitney against the 35 monotherapy reversals, one-sided; it
underflows to 0.0 at these sample sizes and is reported as such rather than
dressed up as a bound. It is also the least interesting column in the table:
with 4,734 combinations against 35 singles, a significant difference is close to
guaranteed and says nothing about whether the difference matters.

Best monotherapy by signed reversal is the **NLRP3 inhibitor** (0.0519),
followed by minocycline (0.0510) and GDNF (0.0481) — all three
neuroinflammation or trophic agents, none of them approved. The best-scoring
monotherapies by *composite* score are the COMT and MAO-B inhibitors, which is
the composite doing its job: they are approved, oral, well-tolerated, and move
almost nothing in the signature (tolcapone: 0.0095).

### Three readings that matter more than the leaderboard

**1. Combination gain is real but small in absolute terms.** The best pair
recovers 0.100 of a signature whose total weight is 1.0. Combination screens of
this class routinely produce differences at this scale; the honest statement is
that the *ordering* is informative and the magnitude is not, because
`target_effects` are unitless directional hypotheses.

**2. Redundancy rises sharply with order.** 12.8% of pairs are sub-additive —
their members cover the same signal — against **36.0%** of triples. This is the
cost of the third agent showing up in the arithmetic rather than in prose.

**3. Most third agents do not earn their place.** Of the 4,734 triples,
**2,856 (60.3%)** have a *negative* `score_gain_over_best_subset`: the triple
scores worse than the best pair inside it, once its added safety burden,
regimen burden, and uncertainty are priced. Median gain is **−0.0192**. Adding a
third drug helps in a minority of cases, and the screen can say which.

## 4. Mechanism strata — the defensible result

**The unit of inference is the mechanism stratum, not the named combination.**

Bootstrap resampling under the curated target-effect uncertainty gives a top-25
Jaccard of **0.238 at order 2** and **0.224 at order 3**, with rank 95% CIs
spanning tens to hundreds of positions. A leaderboard of specific combinations
is therefore not a defensible result, and the runner prints an explicit warning
whenever that Jaccard falls below 0.5. Weight sensitivity is by contrast
excellent (Spearman 0.96 / 0.98 mean under ±50% weight jitter), so the
instability is in the *inputs*, not the weighting.

Stratum medians carry bootstrap intervals that are narrow relative to the spread
between strata. Top and bottom at order 2:

| axis stratum | n | median | 95% CI | q |
|---|---|---|---|---|
| neuroinflammation_control + trophic_support | 15 | 1.246 | [1.078, 1.381] | 0.013 |
| mitochondrial_rescue + trophic_support | 23 | 1.218 | [1.048, 1.408] | 0.013 |
| symptomatic_dopaminergic + trophic_support | 32 | 1.218 | [1.045, 1.364] | 0.0012 |
| synuclein_proteostasis + trophic_support | 12 | 1.185 | [1.042, 1.368] | 0.043 |
| … | | | | |
| symptomatic_dopaminergic + symptomatic_dopaminergic | 61 | 1.101 | [1.014, 1.208] | 1 |
| mitochondrial_rescue + mitochondrial_rescue | 62 | 1.080 | [0.996, 1.195] | 1 |
| synuclein_proteostasis + synuclein_proteostasis | 12 | 0.981 | [0.805, 1.137] | 1 |

**Every one of the top four strata pairs something with `trophic_support`**, and
the same holds at order 3 — the five highest-median triple strata all contain
it. The bottom of both tables is occupied by same-axis pairings.

This is worth stating plainly, because it is also a limitation. The panel
contains **two** trophic agents (exenatide and intraputaminal GDNF) against 16
symptomatic dopaminergic ones, and neither is approved. The screen's strongest
finding is therefore about the axis with the **least** approved chemical matter
in it — the same shape the MS screen produced, where remyelination-pairing
strata outrank every immunomodulation-only stratum and remyelination has no
approved agent at all.

A screen bounded by its panel can identify that gap and cannot, in principle,
fill it. That is what the [de novo design campaign](denovo_design_protocol.md)
exists for, and its independent axis-gap analysis reports `trophic_support` and
`synuclein_proteostasis` at 1.00 unmet fraction for Parkinson's — the same
asymmetry derived by a different route.

## 5. Controls, declared before ranking

| Control | Members | Result |
|---|---|---|
| Positive redundancy | Pramipexole + Ropinirole | **Excluded as expected** (both non-ergot D2/D3 agonists) |
| Safety penalty | Tolcapone (35), Apomorphine (117), Pergolide (125) | None reach the top 25 |
| Negative efficacy | Creatine (97), Coenzyme Q10 (**24**), Isradipine (65), Inosine (88), Cinpanemab (144) | Four of five held out of the top 25 |

65 of 595 pairs were excluded as redundant. No triple was excluded at order 3 —
not because none was redundant, but because the order ladder only enumerates
triples whose three pairs all survived, so redundancy is caught one order down.

**Coenzyme Q10 reaching rank 24 is a reported failure, not a filtered one.**
CoQ10 failed a large phase 3 neuroprotection trial in Parkinson's. It appears
here because the screen scores mechanism and transcriptional direction, not
trial outcome, and CoQ10's mechanistic story is coherent. This is exactly the
limitation the negative controls were declared to expose, and it bounds what the
method can claim: **mechanistic coherence is not evidence of clinical benefit.**

## 6. Known limitations specific to Parkinson's

The [standing limitations](disease_campaign_protocol.md#7-standing-limitations-of-every-campaign)
of every campaign apply. What is different here:

- **The signature is the weakest input.** Literature-curated, not
  cohort-derived, and weaker than the MS entry's. It is the first thing to
  replace.
- **No pharmacokinetic or drug–drug-interaction model.** This gap binds harder
  in Parkinson's than in any disease screened so far. Real PD regimens are
  chronic oral polypharmacy in an elderly population, and the constraints that
  actually govern them are pharmacokinetic: COMT and CYP interactions, additive
  orthostatic hypotension, serotonin syndrome with MAO-B inhibitors, and
  anticholinergic burden. The screen represents none of it. `regimen_burden`
  captures route and half-life spread only. **This is the top-priority next
  model**, and it was deliberately deferred rather than built here, so that PD
  results stay directly comparable with the MS v3 numbers.
- **Symptomatic and disease-modifying agents are ranked on one scale.** Levodopa
  moves a dopaminergic transcript signature and modifies nothing; an LRRK2
  inhibitor may modify the disease and relieve no symptom today. The
  `therapeutic_axes` vocabulary distinguishes them and the stratum analysis
  reports them separately, but a single `signed_reversal` number does not.
- **Two trophic agents.** The strongest stratum result rests on a panel arm with
  n = 2, one of which (GDNF) is delivered by intraputaminal infusion. Read it as
  a statement about the axis, not about those two agents.
- **The order ladder is greedy.** A triple whose members are individually weak
  but jointly excellent is unreachable if one of its pairs was excluded as
  redundant. This is a deliberate trade for tractability and it is stated rather
  than hidden.

## 7. Where this screen ends and design begins

The limitation in §4 — the strongest stratum is the axis with the least
approved chemical matter — is structural, not fixable by extending the screen.
A screen bounded by its panel can only ever return a molecule someone has
already made.

The [de novo design campaign](denovo_design_protocol.md) runs over the same
Parkinson's disease model and independently reproduces the finding. Its
axis-gap analysis, derived from the panel's approved agents rather than from
any combination score, reports:

| therapeutic axis | unmet fraction |
|---|---|
| symptomatic_dopaminergic | 0.00 |
| neuroinflammation_control | 0.81 |
| mitochondrial_rescue | 0.88 |
| **synuclein_proteostasis** | **1.00** |
| **trophic_support** | **1.00** |

Two axes are entirely unserved by approved agents — the same asymmetry the
stratum analysis found from the other direction.

```bash
python -m experiments.design.run_denovo_design \
  --disease parkinsons --quantum-benchmark --k 2 --arms 3 --top 4 \
  --outdir experiments/design/results/parkinsons
```

The campaign derives a 14-requirement target profile led by LRRK2 (0.965),
SLC6A3, NLRP3, MAOB, and GBA1; reports `DDC` and `SLC18A2` as **unreachable**
(the fragment library has no chemical matter for them, which is the most useful
thing a run can say); formulates arm selection as a 10-variable QUBO with 45
couplings and 45 feasible states of 1,024; and confirms enumeration, an exact
eigensolver, and QAOA all reach the same optimum of +0.0830, with QAOA needing
depth ≥ 2.

Its leading design is a **MAO-B inhibitor fused to a caspase-1 warhead**
(`C19H24N2O3`, MW 328.4, CNS-MPO 4.93/6), clearing the CNS gate this registry
entry sets. Nothing about it has been docked, synthesised, or assayed, and it
carries a machine-readable `evidence_status` block naming the 13 assessment
axes on which nothing has been done.

> **A correction worth reading before quoting a novelty number.** This campaign
> previously reported that design's nearest known compound as a *library
> fragment* at Tanimoto 0.32, because the Parkinson's registry entry declared no
> known-structure reference set and the novelty comparison silently fell back to
> the fragments the molecule was assembled from. With
> `data/chemistry/pd_known_structures.json` registered (26 structures), the
> nearest neighbour is **selegiline** at **Tanimoto 0.47**. Still under the 0.6
> novelty threshold, but a materially narrower margin measured against a real
> drug. See
> [the de novo protocol](denovo_design_protocol.md#the-novelty-figure-this-design-used-to-carry-was-wrong-2026-08-28).

## 8. Reproduce

```bash
python -m tools.curate_pd_panel                                    # regenerate + validate the panel
python -m tools.fetch_string_network                               # optional; cached copy is committed
python -m experiments.parkinsons.run_combination_screen --top 25 --seed 7
pytest -q tests/
```

Outputs land in `experiments/parkinsons/results/`:
`pd_combination_screen.json` (full report with provenance) and
`pd_combinations_full.csv` (5,364 rows — every combination at every order,
including the ones excluded from the primary ranking).

Every run is deterministic under a stated seed. The provenance block records a
**content digest of each input file**, the git revision **and whether the tree
was dirty**, Python and package versions, the chemistry backend, the seed, and
the exact command. `--quick` runs a reduced-draw smoke test in about 45 seconds;
the full run takes roughly 9 minutes, most of it the order-3 permutation null
and bootstrap.

## 9. Required validation before publication

1. Pre-register stage (early/motor-complication/advanced), outcome, and weights
   before looking at rankings.
2. Replace the signature with one discovery and one independent validation
   cohort; analyse by disease stage and by *GBA1*/*LRRK2* genotype separately,
   since the panel contains agents targeted at both.
3. Re-derive `target_effects` from measured pharmacology rather than curation.
   The rank instability in §4 is driven by `target_uncertainty`, and reducing it
   is the highest-value fix available.
4. **Build the PK/DDI model** (§6) before any combination here is proposed for
   in-vivo work.
5. Test dose matrices in disease-relevant human systems — iPSC-derived
   dopaminergic neurons, microglial co-culture. Report raw response,
   dose-response fits, and Bliss, HSA, Loewe, and ZIP, not a model score alone.
6. Validate top strata in an appropriate PD model (α-synuclein PFF or
   *LRRK2*-G2019S), assessing exposure, PK, and PD biomarkers.
7. Release code, frozen inputs, seed, full rankings including excluded
   combinations, and the control analysis.
