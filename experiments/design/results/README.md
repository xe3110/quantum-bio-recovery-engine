# Run artifacts

Files in this directory are **snapshots of individual runs**, not curated data
and not a durable record of anything. They are regenerated by re-running the
command recorded in each file's `provenance.command` field, and they are safe
to delete.

The distinction that matters:

| | `data/` | `experiments/*/results/` |
| --- | --- | --- |
| Status | curated, reviewed, version-controlled | disposable run output |
| Changes when | someone makes a curation judgement | any input, seed, or environment changes |
| Cite from it | yes, with its version and digest | only alongside the provenance block |

Every result file carries a `provenance` block recording the SHA-256 digest of
every input, the git revision **and whether the tree was dirty**, the
interpreter, the tracked package versions, and the active chemistry backend.
That last one matters: RDKit being importable changes descriptor values and
therefore rankings, so two runs of the same command in different environments
can legitimately disagree.

A number from one of these files is not interpretable without the digests that
accompany it.
